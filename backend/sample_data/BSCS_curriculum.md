# Program: BSCS - Bachelor of Science in Computer Science

Curriculum document, academic year 2026-27. Approved by the Board of Studies.

## Programme Learning Outcomes

- PLO1: Apply knowledge of computing fundamentals and mathematics to solve computing problems.
- PLO2: Analyse a problem and identify the computing requirements appropriate to its solution.
- PLO3: Design, implement and evaluate computer-based systems, processes, components or programs.
- PLO4: Communicate effectively about technical work with a range of audiences.

## Course: CS101 - Introduction to Programming

Credits: 3
Prerequisites: None
Description: Fundamentals of programming in Python: variables, control flow, functions and simple data structures.

### Units

- Unit 1: Variables, Types and Expressions — CLO1, CLO2
- Unit 2: Control Flow — CLO3
- Unit 3: Functions and Modularity — CLO4, CLO5

### Course Learning Outcomes

- CLO1: Explain how variables, data types and assignment work in a Python program. (Unit 1)
- CLO2: Evaluate arithmetic and boolean expressions following operator precedence rules. (Unit 1)
- CLO3: Construct programs that use conditional statements and loops to solve problems. (Unit 2)
- CLO4: Write functions with parameters and return values to decompose a problem. (Unit 3)
- CLO5: Trace the execution of a recursive function and identify its base case. (Unit 3)

### CLO-PLO Mapping

- CLO1 -> PLO1
- CLO2 -> PLO1
- CLO3 -> PLO2, PLO3
- CLO4 -> PLO3
- CLO5 -> PLO2

## Course: CS201 - Data Structures

Credits: 3
Prerequisites: CS101
Description: Linear and non-linear data structures, their implementation and complexity analysis.

### Units

- Unit 1: Algorithm Analysis — CLO1
- Unit 2: Linear Structures — CLO2, CLO3
- Unit 3: Trees — CLO4

### Course Learning Outcomes

- CLO1: Analyse the time complexity of simple algorithms using Big-O notation. (Unit 1)
- CLO2: Implement stacks and queues and apply them to solve problems. (Unit 2)
- CLO3: Compare arrays and linked lists for insertion, deletion and access operations. (Unit 2)
- CLO4: Traverse binary search trees using in-order, pre-order and post-order traversal. (Unit 3)

### CLO-PLO Mapping

- CLO1 -> PLO1, PLO2
- CLO2 -> PLO3
- CLO3 -> PLO2
- CLO4 -> PLO3

## Course: MATH110 - Discrete Mathematics

Credits: 3
Prerequisites: None
Description: Logic, sets, functions and counting for computing.

### Units

- Unit 1: Logic and Proofs — CLO1, CLO2
- Unit 2: Sets and Counting — CLO3

### Course Learning Outcomes

- CLO1: Translate English statements into propositional logic and build truth tables. (Unit 1)
- CLO2: Proofs. (Unit 1)
- CLO3: Apply the rules of sum and product and permutations to counting problems. (Unit 2)
